# 设置页两级菜单设计（书架工具栏收进设置）

日期：2026-11-17

## 背景

书架页顶部挤了 10 个入口按钮（管理、书仓、书签、替换规则、缓存、账号、统计、检查更新、刷新缓存、导入），手机上一行放不下，也把「这张页面是看书用的」这件事淹没了。设置页目前是单页长表单 + 一条扁平功能列表，没有层级。

## 目标

- 书架只保留浏览相关操作（最近阅读、分组筛选、布局切换、进入设置）。
- 所有工具与账号入口收进设置，设置页有清楚的两级结构：一级分类、二级条目。
- 一级分类可深链接：`/settings/account`、`/settings/shelf`、`/settings/data`、`/settings/system`。
- 导入本地书、批量管理、分组管理、检查更新、刷新缓存这些「动作」在设置里就能完成，不必回书架。
- 手机端一级菜单横向滑动，桌面端左侧竖排；沿用现有暖白/品牌橙视觉与 CSS 变量。

## 非目标

- 不改任何后端 API；书仓、书签、统计、备份、WebDAV 等详情页保持原路由与原页面。
- 不做主题切换、字号设置等新功能。
- 不重构阅读器或书籍详情。

## 方案（已选 A）

一级分类做左侧竖排导航（手机横向 chips），右侧渲染该分类下的二级条目。二级条目分三类：

- **链接**：跳到已有页面（书仓 `/warehouse`、书签 `/bookmarks`、缓存 `/cache`、替换规则 `/replace`、统计 `/stats`、备份 `/backup`、WebDAV `/webdav`、用户管理 `/users`）。
- **动作**：留在设置里执行（导入本地书、检查更新、刷新缓存、退出登录）。
- **内联面板**：账号信息、修改密码、用户列表、分组管理、系统状态、关于。

备选：

- **B 单页分组**（iOS 设置风格，一级是分组标题、二级是行）：少一层导航，但「一级菜单」不可深链接，切分类要长滚动；用户明确要两级菜单，舍。
- **C 每个二级条目一条路由**：层级最彻底，但设置页要多一层路由与返回逻辑，且详情页本来就有独立路由，重复；舍。

## 设计

### 路由

`/settings/:section?`，缺省 section 为 `account`；未知 section 回落到 `account`。底部导航与旧链接 `/settings` 继续有效。

### 一级菜单

| id | 名称 | 二级内容 |
|---|---|---|
| `account` | 账号 | 账号信息、修改密码、用户管理（管理员）、退出登录 |
| `shelf` | 书架 | 导入本地书、批量管理、分组管理、书仓、书签、缓存管理、替换规则、检查更新、刷新缓存 |
| `data` | 数据 | 阅读统计、备份与恢复、WebDAV |
| `system` | 系统 | 运行状态、关于 |

### 书架页

- 删除整条 `.shelf-toolbar`（含隐藏 file input）。
- `page-head` 增加「设置」入口（跳 `/settings/shelf`）。
- 空书架文案改为「去 设置 → 书架 → 导入本地书」。
- 分组 tabs 保留筛选，移除「管理」按钮与分组弹层；分组管理移到设置。
- 批量管理入口改由设置跳 `/bookshelf?manage=1`；书架读取 query 进入多选，选中栏提供「退出管理」。

### 交互细节

- 检查更新：复用现有轮询逻辑，结果显示在条目描述里，并 toast。
- 刷新缓存：取最近阅读的前 5 本，`cacheBook(url, 20, true)`，显示进度/结果。
- 导入：隐藏 file input，选择文件后上传并 toast「已加入《书名》」。
- 分组管理：新建输入框 + 列表（改名/删除），操作后刷新。
- 退出登录：`api.logout()`、清 token、跳 `/login`。
- 顺带修复 `App.vue` 缺少 `api` / `setToken` import 的问题（当前运行时会报未定义）。

### 样式

在 `ui.css` 末尾新增 `.settings-*`：`settings-layout`（桌面 220px + 1fr 网格）、`settings-nav`/`settings-nav-item`（手机横向滚动）、`settings-panel`、`settings-card`、`settings-row`（链接/动作/信息行统一）、`settings-kv`。全部使用现有 `--color-*` / `--radius-*` / `--space-*` 变量。
